# MINYAWE-LINK

**v8.0 — Vercel Edition** — نظام استضافة ملفات سحابي 100%، بيسلمك لينكات مباشرة على دومين موقعك، من غير ما الملفات تعدي على السيرفر أصلاً (صفر استهلاك للـ Fast Origin Transfer في حساب Vercel).

By **ELMINYAWE**

---

## الفكرة الجديدة في V8

الموقع بيشتغل **حلقة وصل**: أنت بترفع، الملف بيتخزن عند مزودين سحابيين، وأي حد بيفتح لينكاتك بيشتغل من دومينك أنت (`/v` `/e` `/d`) — **مفيش أي لينك مزود بيتظهر للمستخدم** في الواجهة.

### إزاي الحصة الشهرية بتاعتك بتفضل سليمة؟

| المسار | قبل (V7) | بعد (V8) |
|---|---|---|
| **رفع ملف** | الملف بيعدي من السيرفر للمزود | المتصفح يرفع **مباشرة** للمزود — الملف مش بيلمس Vercel |
| **تشغيل / تحميل** | السيرفر يعمل proxy للملف كامل | **تحويلة 302** — المزود يبعت الملف للمستخدم مباشرة |
| **اللي بيطلع من حسابك** | حجم الملفات كامل | كيلوبايتات (صفحات HTML + استجابات JSON) |

> حسب حدود Vercel: الـ Fast Origin Transfer بيحتسب بايتات استجابة الفانكشن — وفي التصميم ده الفانكشن بيرجّع تحويلة 302 (حوالي 200 بايت) مهما كان حجم الملف.

## المزودون السحابيون (كله بدون تخزين محلي)

| الأولوية | المزود | الحد | مدة الاحتفاظ | ملاحظات |
|---|---|---|---|---|
| 1 | **OnlyFiles** | 100MB | **دائم** | الرفع المباشر من المتصفح — الملف مش بيلمس السيرفر أصلاً |
| 2 | **Pixeldrain** | 20GB | دائم مع keep-alive يومي | بيضاف تلقائياً لو `PIXELDRAIN_API_KEY` موجود — كرون يومي بيلمس الملفات عشان مؤقت عدم النشاط عمره ما يخلص |
| 3 | **0x0.st** | 512MB | 30 يوم → سنة (بتجدد مع الاستخدام + keep-alive) | احتياطي أخير |
| — | **Catbox** (معطّل افتراضياً) | 200MB | دائم | بيحجب كل عناوين IP المراكز البيانات — وفيها سيرفرات Vercel. للتفعيل من بروكسي خاص: `ENABLE_CATBOX=true` + `CATBOX_USERHASH` |

لو مزود فشل أو علق، الملف بيروح للمزود اللي بعده تلقائياً (مع دايرة أمان بتتخطى المزود المعلق 10 دقايق).

### ليه Catbox معطّل؟

اتجرب عملياً: الاتصال بـ catbox.moe من عناوين مراكز البيانات بيحصل timeout كامل حتى قبل استقبال الطلب — وده شامل سيرفرات Vercel (AWS). مفيش userhash هيغير ده. لو حبيت ترجّعه لازم IP سكني/بروكسي خاص، ساعتها فعّل `ENABLE_CATBOX=true` وهيدخل آخر السلسلة أوتوماتيك.

## النشر على Vercel (خطوة بخطوة)

1. ارفع الكود على GitHub (أو استخدم الريبو ده مباشرة).
2. في Vercel: **Add New → Project → Import** الريبو.
3. Framework Preset: **Other** — متغير حاجة، الإعدادات جاهزة في `vercel.json`.
4. اعمل قاعدة بيانات: **Storage → Create Database → Postgres (Neon)** — واربطها بالمشروع. الـ `DATABASE_URL` هيتضاف أوتوماتيك.
5. ضيف متغيرات البيئة من **Settings → Environment Variables**:
   ```
   ADMIN_TOKEN=<سر قوي>
   MAX_FILE_SIZE_MB=100
   PIXELDRAIN_API_KEY=<مفتاح pixeldrain بتاعك>
   ```
   اختياري:
   ```
   RATE_MAX=60
   BASE_URL=https://<دومينك>
   CRON_SECRET=<سر حماية إضافي للكرون>
   ```
6. **Deploy** — وخلاص.
7. اتأكد: `https://<دومينك>/health` يرجع `MINYAWE-LINK OK`.

الجداول بتتعمل أوتوماتيك أول تشغيل (مفيش migrations يدوية).

### الصيانة الدورية

Cron يومي (3:00 UTC) بيضرب على `/api/cron/maintenance` — بينضف الملفات المنتهية والكاش والإشعارات والسجل، **وبعمل keep-alive لكل الملفات الموجودة على pixeldrain و0x0** (طلب GET صغير بيجدد مؤقت النشاط عندهم — حماية من الحذف بسبب عدم الاستخدام). الملفات المنتهية كمان بتتحذف فوراً لو حد حاول يفتحها (lazy expiry).

## التشغيل المحلي

```bash
npm install
ADMIN_TOKEN=secret npm start        # بدون DATABASE_URL → مخزن JSON تجريبي في ./data
# أو مع Postgres:
DATABASE_URL=postgres://... ADMIN_TOKEN=secret npm start
```

> ملاحظة: الوضع المحلي بدون DATABASE_URL للتجربة فقط — على Vercel لازم Postgres لأن مفيش تخزين دائم.

## مسارات الرفع

### 1) الرفع المباشر من المتصفح (الأساسي — أي حجم لحد 100MB)
المتصفح يرفع على `https://api.onlyfiles.com/v1/upload` (حقل `file`) ثم يسجّل الملف عندنا:
```
POST /api/register
{
  "provider": "onlyfiles",
  "fullUrl": "https://onlyfiles.com/ID/name.jpg",
  "providerId": "ID",
  "filename": "name.jpg",
  "size": 12345,
  "expiry": "never",
  "alias": "optional",
  "password": "optional"
}
```

### 2) عبر السيرفر (للأدوات زي ShareX / curl — حد 4.5MB بسبب حدود Vercel)
```
POST /api/upload (multipart: file + expiry + alias? + password?)
```

## اللينكات (كله على دومينك)

| المسار | الوظيفة |
|---|---|
| `/v/:id` | صفحة معاينة بالمشغل (صور/صوت/فيديو/نصوص/PDF) |
| `/o/:id.ext` | مشغل مباشر — العنوان يفضل على دومينك |
| `/p/:id.ext` | عارض PDF مدمج (حتى 25MB) — كاش على حواف Vercel |
| `/e/:id.ext` | بث مباشر — 302 للمزود (Range مدعوم من المزود) |
| `/d/:id.ext` | تحميل مباشر — 302 للمزود |
| `/i/:id` | لينك قصير — 302 |
| `/a/:id` | صفحة ألبوم |

## API كامل

`/api/docs` — توثيق JSON آلي | `/llms.txt` — دليل AI agents | `/api/config` — الحدود والحالة

### إدارة (header `x-admin-token` أو `?admin=TOKEN`)
| Method | Path | الوصف |
|---|---|---|
| GET | `/api/admin/ping` | التحقق من التوكن |
| POST | `/api/:id/password` | تعيين/تغيير/إزالة باسورد |
| GET | `/api/admin/files?q=` | قائمة الملفات + بحث |
| GET | `/api/admin/audit?q=&limit=` | سجل العمليات |
| GET | `/api/admin/backup` | نسخة احتياطية JSON (ملفات + سجل) |
| GET | `/api/cron/maintenance` | تشغيل الصيانة يدوياً |

## ملاحظات

- **الاحتفاظ الافتراضي: دائم** — الخيارات: `1h` / `24h` / `7d` / `30d` / `never` (الافتراضي permanent). المدة بتتحكم في اللينك عندنا فقط؛ الملف على المزود بيفضل موجود والkeep-alive بيحافظ عليه.
- الباسوردات متشفرة بـ **scrypt**.
- الامتدادات المحظورة: الملفات التنفيذية (`.exe` `.scr` `.bat` `.ps1` `.jar` `.msi` `.dll`).
- عناوين المزودين مش بتظهر في أي واجهة — كله لينكات دومينك (تحويلة 302 شفافة).
- الكود القديم (Railway/Docker): `Dockerfile` شغال للتشغيل الذاتي على أي سيرفر.
