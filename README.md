# MINYAWE-LINK

**v7.0** — نظام استضافة ملفات متكامل مع تخزين سحابي متعدد، إشعارات، مراقبة صحة، ومشاركة اجتماعية.

## الميزات الرئيسية

### التخزين السحابي المتعدد
- **Catbox** (أساسي) — مجاني بدون حساب
- **0x0.st** (احتياطي) — مجاني بدون حساب
- **file.io** (احتياطي) — مجاني بدون حساب
- **التخزين المحلي** (أخير) — خيار احتياطي فقط إذا فشل جميع المزودين

### قاعدة البيانات
- **SQLite** مع وضع WAL للأداء العالي
- جداول: الملفات، الألبومات، الإشعارات، التحليلات، سجل التدقيق، التخزين المؤقت
- فهارس للبحث السريع

### الإشعارات
- إشعارات فورية للرفع والحذف والانتهاء
- إشعارات أمنية وتخزين ونظام
- إشعارات للمسؤول + أحداث مهمة للمستخدمين

### مراقبة الصحة
- فحص مساحة القرص وقاعدة البيانات والذاكرة
- فحص الخدمات الخارجية (Catbox, 0x0.st)
- إرسال إشعارات تلقائية عند المشاكل
- فحص دوري كل 60 ثانية

### التخزين المؤقت
- ذاكرة مؤقتة في الذاكرة (Map)
- تخزين مؤقت في قاعدة البيانات
- تنظيف تلقائي للبيانات المنتهية

### التحميل الاستئنافي
- دعم Range requests للتحميل
- دعم Range requests للبث (streaming)
- معالجة أخطاء البث

### المشاركة الاجتماعية
- زر مشاركة واحد يفتح قائمة بالوسائل
- دعم: واتساب، تيليجرام، X، فيسبوك، لينكدإن، ريديت، بريد، رسالة

### الميزات الأخرى
- رفع متعدد (حتى 10 ملفات) مع شريط تقدم
- حماية بكلمة مرور لكل ملف (scrypt hash)
- انتهاء صلاحية تلقائي (1h/24h/7d/30d)
- لوحة تحكم للمسؤول مع سجل تدقيق
- نسخ احتياطي ZIP
- ألبومات ملفات
- عداد مشاهدات
- أسماء مخصصة (slugs)
- واجهة برمجة تطبيقات (API) مع توثيق
- رفع بالسحب والإفلات واللصق
- رموز QR

## البدء السريع

### Railway (موصى به)
1. ادفع هذا المستودع إلى GitHub
2. Railway → مشروع جديد → انشر من مستودع GitHub
3. أضف Volume مع Mount Path: `/data`
4. أضف المتغيرات:

```
ADMIN_TOKEN=<اختر-سر-قوي>
MAX_FILE_SIZE_MB=200
BASE_URL=https://<your-domain>.up.railway.app
DATA_DIR=/data
```

5. Networking → Generate Domain → عيّنه كـ `BASE_URL` وأعد النشر
6. تحقق: `/health` يرجع `MINYAWE-LINK OK`

### محلي / Docker

```
npm install
PORT=3000 DATA_DIR=./data ADMIN_TOKEN=secret npm start
```

## متغيرات البيئة

| المتغير | الوصف | الافتراضي |
| --- | --- | --- |
| `ADMIN_TOKEN` | يفعّل لوحة التحكم وAPI الإدارة (مطلوب للإدارة) | — (الإدارة معطلة) |
| `BASE_URL` | الرابط العام المستخدم لبناء روابط المشاركة | يُكتشف تلقائياً |
| `DATA_DIR` | دليل البيانات (قاعدة البيانات + الرفعات + سجل التدقيق) | `/data` |
| `MAX_FILE_SIZE_MB` | الحد الأقصى لحجم الملف | `200` |
| `RATE_MAX` | الحد الأقصى للطلبات لكل IP كل 10 دقائق | `60` |
